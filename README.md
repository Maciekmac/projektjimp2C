# Projekt JIMP2

Repozytorium zawiera obie części projektu podzielone na osobne foldery:

* **/czesc1-C** – Pierwsza część projektu napisana w języku C. W podfolderze `projektjimp2C/` znajduje się dedykowana dokumentacja (funkcjonalna, implementacyjna i końcowa). Budowanie za pomocą `make`.
* **/czesc2-java** – Druga część projektu napisana w języku Java.
